# История версий

## 2.0.0 — этап III (ПР 9–14)

**Новое**
- Вход по e-mail и паролю, токены Bearer со сроком 8 ч, выход с отзывом токенов, роли и права (FR-11).
- Перевод проекта по этапам производства с правилами переходов и историей статусов (FR-08, FR-13).
- Съёмочная группа проекта: добавление, смена роли, исключение (FR-10).
- Бронирование оборудования без пересечений по времени, расписание единицы оборудования (FR-09).
- Отчёт о загрузке сотрудников (FR-12), поиск и постраничный вывод проектов, редактирование и удаление задач.
- REST API 2.0: 31 операция, спецификация OpenAPI 3.0 (`/api/openapi.json`), Swagger UI (`/api/docs`).
- Миграции схемы БД (`python -m app.manage migrate`), журнал `schema_migrations` с контрольными суммами.
- HTTPS через nginx, ограничение частоты запросов, заголовки безопасности (CSP, HSTS и др.).
- Журнал в JSON с X-Request-ID, метрики Prometheus, правила оповещений, резервное копирование и восстановление.

**Изменения, требующие внимания при обновлении с 1.0**
- Все ресурсы API, кроме `/api/health` и документации, требуют токен. После обновления задайте пароли:
  `docker compose run --rm -T migrate python -m app.manage set-password EMAIL`.
- Тело `/api/health` расширено (version, schema, db_ms, uptime_s); поля `status` и `db` сохранены.
- Приложение доступно через прокси: https://127.0.0.1:8443 (http://127.0.0.1:8080 перенаправляет на HTTPS).

**Совместимость:** миграции 0002–0004 только добавляют объекты, поэтому версия 1.0 продолжает работать
на схеме 2.0. Это позволяет откатить приложение без восстановления БД.
